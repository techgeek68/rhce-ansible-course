# RHCE Ansible Course: Red Hat Enterprise Linux Automation with Ansible

A self study course for the RHCE exam (EX294), with a complete lab you build on your own virtual machines. Every chapter combines a lesson, guided exercises, a quiz, and a graded lab that you check with the same `lab start | grade | finish` workflow as a classroom.

> This is an independent, community course. It is not produced, endorsed, or supported by Red Hat. Red Hat, RHEL, and Ansible are trademarks of Red Hat, Inc. Always check the current official EX294 objectives before your exam.

---

## How to Study This Course

Work **in order**. Every page has a navigation bar at the top and **Previous / Next** links at the bottom, so you can go through the whole course without coming back here.

1. **Build the lab once:** follow [00 Lab Setup](00_lab_setup/README.md) from Step 1 to Step 6 on one page. It ends with a verified lab and `baseline` snapshots. The second page of that chapter is an optional reference on how the `lab` command works.
2. **For every chapter**, follow the numbered pages:

   | Step | What you do | Where |
   |---|---|---|
   | Lesson | Read the chapter `README.md`; each section names the exercise that practices it | Chapter directory |
   | Guided exercises | `lab start NAME`, follow the steps, `lab finish NAME` | `01_guided_exercise_*.md` and following |
   | Quiz | Answer everything before opening any answer | `NN_quiz.md` |
   | Graded lab | `lab start`, solve it within the time limit **without** the lesson, `lab grade` until every check passes, `lab finish` | `NN_lab.md` |
   | Solution | Only after grading; compare decisions, not just results | `NN_lab_solution.md` |

3. **Before the exam**, redo every graded lab from a fresh `lab start` and beat its time check.

Files are numbered in study order inside each chapter, so the GitHub file list already shows the sequence.

