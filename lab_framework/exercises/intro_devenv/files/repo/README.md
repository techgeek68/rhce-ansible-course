# intro_devenv

Starter project for the Chapter 1 guided exercise on the Ansible development environment.

| File | Purpose |
|---|---|
| `ansible.cfg` | Project settings: inventory location and remote user |
| `inventory` | One managed host: servera |
| `hello.yml` | Playbook you edit and run inside the development container |
| `solutions/` | Finished versions of every file you change |
